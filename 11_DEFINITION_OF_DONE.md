# RETOS Mentor — Definition of Done

Una tarea está terminada cuando:

```text
□ Cumple criterios de aceptación
□ Compila
□ Respeta arquitectura
□ Respeta API Contract
□ No duplica funcionalidad
□ Maneja errores relevantes
□ Tests pasan
□ No expone secretos
□ Responsable humano revisó
```

Integración:
```text
□ QA validó
```

Cierre de semana:
```text
□ E2E del líder aprobado
```

Un agente diciendo "completed successfully" no equivale a Definition of Done.
