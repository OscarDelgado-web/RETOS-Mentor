# RETOS Mentor — Paquete de trabajo Semana 1

**Periodo:** domingo 4 al sábado 10 de octubre de 2026

## Objetivo
Construir el primer vertical slice funcional de RETOS Mentor y establecer una forma de trabajo común para seis integrantes y distintos agentes de IA.

## Resultado esperado

```text
Estudiante demo
    ↓
Selecciona carrera / asignatura / tema
    ↓
Escribe una pregunta
    ↓
Frontend
    ↓
Backend
    ↓
Consulta contexto básico del estudiante
    ↓
LLM
    ↓
Respuesta contextual
    ↓
Frontend
```

## Principio
La IA puede producir gran parte del trabajo operativo, pero el equipo humano conserva la responsabilidad sobre arquitectura, integración, calidad, seguridad y decisiones finales.
