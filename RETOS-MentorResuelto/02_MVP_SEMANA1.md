# RETOS Mentor — MVP Semana 1

## Objetivo
Construir el primer vertical slice funcional del producto.

## Incluido
- frontend base;
- backend base;
- PostgreSQL;
- datos demo;
- contexto básico de estudiante;
- carrera / asignatura / tema;
- envío de pregunta;
- llamada al LLM;
- respuesta en frontend.

## Excluido
- RAG;
- carga de PDF;
- embeddings;
- pgvector;
- evaluaciones adaptativas;
- mastery definitivo;
- recomendaciones avanzadas;
- portal docente;
- gamificación;
- notificaciones;
- app móvil nativa.

## Definition of Success
```text
Frontend → Backend → PostgreSQL → LLM → Frontend
```
debe funcionar de extremo a extremo con un estudiante demo.
