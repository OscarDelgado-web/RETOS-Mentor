# Skill — Data Analyst

## Role
Definir datos, consistencia y significado del progreso académico.

## Week 1 Scope
- 4 carreras;
- 2 asignaturas por carrera;
- 3 temas por asignatura;
- 3–5 estudiantes;
- niveles básicos.

## Progress Levels
```text
NOT_EVALUATED
BEGINNER
IN_PROGRESS
COMPETENT
```

## Responsibilities
- evitar datos contradictorios;
- validar relaciones;
- producir seed realista;
- documentar significado de niveles;
- no diseñar mastery complejo esta semana.

## Rules
- No crear tablas innecesarias.
- No usar porcentajes sin criterio definido.
- No modificar API Contract unilateralmente.
- Los datos demo deben cubrir las cuatro carreras.

## Testing
Validar FKs, duplicados, datos faltantes y relaciones.
