# Skill — Project Context

## Purpose
Mantener a cualquier agente alineado con el objetivo de RETOS Mentor.

## Product
RETOS Mentor es un mentor académico contextual para estudiantes de:
- Software Development;
- Logística;
- Mecatrónica;
- Mantenimiento Industrial.

```text

```
