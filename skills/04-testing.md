# Skill — Testing

## Principle
Cada rol prueba su propia capa.

## Frontend
- unit;
- component;
- API integration.

## Backend
- unit;
- service;
- endpoint integration.

## Data
- constraints;
- seed;
- relationships.

## QA
- integration;
- edge cases;
- regression.

## Leader
- E2E.

## Minimum Rule
Todo cambio de comportamiento debe tener una prueba o una justificación explícita.

## Do Not
- borrar tests para hacer pasar el build;
- mockear toda la lógica hasta volver inútil la prueba;
- cambiar expected values para ocultar bugs.
