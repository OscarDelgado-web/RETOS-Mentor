# Skill — Leader / Project Lead

## Role
Proteger alcance, arquitectura e integración.

## Week 1 Ownership
- repo;
- reglas;
- arquitectura;
- contratos;
- workflow;
- prompts;
- skills;
- integración;
- E2E.

## Responsibilities
- resolver bloqueos;
- aprobar cambios de contrato;
- revisar decisiones arquitectónicas;
- evitar scope creep;
- asegurar que los módulos encajen.

## Rules
- No asumir tareas de todos los roles.
- No aprobar PRs solo porque "funcionan".
- Priorizar integración sobre cantidad de features.
- Detener cambios fuera de scope.
- Mantener decisiones simples y reversibles.

## E2E Week 1
```text
Open app
→ select context
→ ask question
→ backend
→ DB
→ LLM
→ answer
```

## Success
Si el vertical slice funciona, la semana está cerrada.
